# Student Management System

Python OOP Practice: Class model (`Student`, `Name`, `Date`) for student management using composition.

## 🚀 Features

* **Object-Oriented Programming (OOP):** Deep implementation of encapsulation, inheritance, and composition.
* **Data Validation:** Strict property getters and setters ensuring data integrity (e.g., regex-based name validation and logical date verification).
* **Type Hinting:** Fully annotated Python code for better IDE support and architectural clarity.
* **Modular Design:** Separation of concerns across independent class files.

## 📂 Project Structure

```text
student-management-oop/
├── date.py        # Date class handling day, month, year and validation
├── name.py        # Name class handling formatting and regex validation
├── student.py     # Main Student entity utilizing composition
└── main.py        # Entry point and testing instances
